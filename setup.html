MC22 Setup Required

Open config.js and replace the two placeholder values with your Supabase Project URL and anon/public key. Then reload.

  1. Create a Supabase project.
  2. Run the SQL in supabase_setup.sql.
  3. Create the agent-photos storage bucket and make it public.
  4. Enable Email/Password authentication and create leader accounts.
  5. Paste the URL and anon key into config.js.
  6. Upload all files to GitHub Pages.

Never use a service_role key in this website.
